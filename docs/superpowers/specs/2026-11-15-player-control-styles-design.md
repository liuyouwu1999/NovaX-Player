## 1. 背景与动机

用户（项目所有者）反馈：现有控制层唤起时会挡住视频内嵌字幕（字幕常在画面底部），即使加了半锁（不出控制层的手势态）部分用户仍不满意——他们偏好 nPlayer 式极简控制面；同时另一部分用户很喜欢现有样式。另有一类「只用过长视频 App」的用户（NAS 场景中家人的典型画像）对本地播放器布局不熟悉。

结论：**做控制层样式可切换**（三套），样式不同、功能对等，主播放器与 RMVB 兜底播放器同口径。

关键先例：nPlayer 官方内置双皮肤（Classic / Simple Line，设置与播放中均可切）证明该功能形态成熟、用户接受度已被验证。

## 2. 目标与非目标

### 目标
1. 三套控制层样式：**经典**（现状紧凑化）/ **极简**（nPlayer 1:1 复刻，rev5）/ **长视频风**（优酷式，服务长视频 App 习惯用户）
2. 功能对等原则：**功能不丢，但位置/形态可变**——「更多」面板扩容为功能全集兜底（§5.5），手势语义不变
3. 双切换入口：设置页（带样式预览示意图，不盲切）+ 播放中「更多」面板（**主播放器与 RMVB 两侧都加**），均即时生效
4. 主播放器与兜底播放器永远一致（技术手段：收拢 RMVB 顶栏副本为共享组件 + 同一风格分发）
5. 经典样式紧凑化：底栏总高 154dp → 122dp（-21%），布局、间隔比例、宽/窄双形态完全不变（trackInset 连带变化见 §3.1 注）

### 非目标（明确不做）
- ❌ 强调色自定义（nPlayer 的 Color 功能）
- ❌ per-视频样式记忆（全局一份）
- ❌ 七个功能面板（Subtitle/Audio/Speed/Aspect/Quality/Info/More）**视觉换肤**——三套样式共用同一套面板；唯一例外是 More 面板**内容扩容**（§5.5，内容级非视觉级，且三样式共用同一份扩容）
- ~~❌ 极简档常驻时间小字的可关设置（固定常驻）~~（**rev5 作废**：常驻层整体删除，本条前提不复存在）
- ❌ 顶栏高度调整（用户只要求下方）
- ❌ 新增任何功能面板（长视频风的选集 = 既有上/下集键 + 更多面板，不新做选集面板）
- ❌ RMVB 手势机与主播放器的已知差异统一（双击分区 1/4-1/2-1/4 vs 1/5-3/5-1/5 维持现状，防回归面扩大——挂账见 §11）
- ❌ 外挂字幕位置避让（调研中的补充思路，不做）

## 3. 样式定义

存储枚举值：`classic`（默认）/ `minimal` / `streaming`。

### 3.1 经典（classic）＝现状 + 紧凑化

布局零变化，仅压缩尺寸（宽幅横屏；来源实测 PlayerControls.kt）：

| 区块 | 现状 → 紧凑 | 备注 |
|---|---|---|
| NvPlayerBottomBar Column bottom padding | 10 → 6dp | |
| NvChapterSlider 触摸热区 | 56 → **48dp**（用户拍板保 48） | 视觉轨道不变（静息 5dp/拖动 8dp、旋钮半径 6/11dp——2026-10-10 S2 改版现行值）；时间贴轨展示不变 |
| NvChapterSlider 拖动气泡 | 气泡锚点上移 8dp | 评审 P1-2：48dp 热区下旋钮顶缘（≈23dp）与气泡底（≈30dp）重叠约 7dp（56dp 时恰不碰）；上移消重叠，「拖动预览气泡不变」指内容与交互，位置微调 |
| NvPlayerControlRow padding top / bottom | 2 / 14 → 1 / 9dp | |
| 暂停钮 PauseSlot | 72 → 58dp，icon 34 → 30dp | |
| 侧键触区（锁/上下集/快退进/倍速） | 60 → 48dp，icon 28 → 24dp | 行高由暂停钮决定，此项只收紧键间呼吸感 |
| **底栏总高** | **154 → 122dp** | **-32dp（约 21%）**；该值为 NvPlayerBottomBar 自身高，不含主播放器偶发叠加的无字幕横幅/还原画面钮（验收口径排除横幅态） |

窄幅档位（`nvNarrowControlMetrics`）同步压缩，比例与三段中心锚定布局不变：

| 档位（maxWidth） | pause 现状 → 新 | 侧键 btn 现状 → 新 | rowIcon |
|---|---|---|---|
| ≥380dp | 62 → 50dp | 52 → 42dp | btn×0.48 比例不变 |
| ≥330dp | 56 → 45dp | 46 → 38dp | 同上 |
| 其余 | 50 → 40dp | 42 → 36dp | **固定 18dp 下限**（36×0.48≈17.3 偏小，最小档 icon 取 18dp，评审 P2-1） |

连带变化（如实记录，评审 P2-2）：窄幅进度条 `trackInset = btn×0.26` 随 btn 缩小而减小 → 窄幅进度条两端向屏缘各延伸约 1.5~2dp，属紧凑化的自然结果。

顶栏（NvPlayerTopBar，56dp 高 / 48dp 键位 / 26dp icon）不动。

### 3.2 极简（minimal）＝ nPlayer 1:1 复刻（rev5，用户第三次拍板 2026-11-18）

用户提供 nPlayer 真机截图两轮（2026-11-15 一张 / 2026-11-18 四张横屏）。**rev5 修正 rev4 的三处理解错误**（用户明确指出，附截图实证）：

| # | rev4 错误 | rev5 修正（nPlayer 实际） |
|---|---|---|
| 1 | 进度条放底部（贴底细线，常驻层+唤起态都是底线） | **顶栏本身就是进度条**：蓝色填充=已播比例，整栏可拖动/点击跳转；**底部没有任何进度条**（nPlayer 截图底缘细灰线=系统手势条，非进度条） |
| 2 | 左侧第一圆钮放了锁 | 左一是**画面旋转**（点按 0°→90°→180°→270° 循环，用户原话「按一下90度再按一下180度」；复用既有 rotateVideo，PlayerScreen 现行为一致）；锁只在底栏首钮 |
| 3 | 保留常驻层（贴底细线+时间小字） | **控制层隐藏后画面完全干净**（零常驻元素）——这才是「不挡字幕」的完整含义 |

rev2 的"几乎无按钮"设计与 rev4 的贴底细线/常驻层**均作废**。色板沿用：蓝块 `#4578C7`（NvPlayerBlue）、侧圆钮半透明灰底（黑 55% 附近叠画面）、底栏半透明黑条。

**唤起态（rev5 布局）**：

```
[蓝✕] 22:40  [文件名标题]  -22:39 [蓝⋯]     ← 顶栏=进度条（48dp）：蓝色填充从左缘
████████████████████░░░░░░░░░░░░░░░░░░░░      长到已播比例，未播段半透明深色透出画面；
│                                                  │     整栏可拖动 scrub / 单点定跳
(旋)                                          (⊕)
(字)                                        (1.0x)
(齿)                                          (⊖)
│                                                  │
🔒 ⏮上集 ⏪快退 ⏸暂停 ⏩快进 ⏭下集 ⛶比例        ← 底栏：纯按钮黑条（之下什么都不画）
          （画面中央区无遮挡；底下没有任何进度条）
```

- **顶栏＝进度条（新组件 MinimalSeekTopBar，高 48dp）**：
  - 元素与布局（rev4 沿用）：蓝✕块（`#4578C7` 圆角方块白图标，**通栏高 48dp 见方**，=退出播放器）→ 当前时间（**复用仓内 formatTime**）→ 文件名标题（居中弹性占位，省略号截断）→ 剩余时间（`-45:17` 负号格式 = durationMs−positionMs；**durationMs≤0（直播/无时长）时隐藏**）→ 蓝块图标改**横三点 ⋯**（`Icons.Filled.MoreHoriz`，material-icons-extended 已在依赖；rev4 用竖⋮ 与 nPlayer 不符，1:1 轮一并修正）=精简「播放管理」菜单入口（见下）。`#4578C7` 入 NvColors 体系不散落硬编码
  - **进度填充视觉**：已播段=实色 `NvPlayerBlue` 从栏最左缘（x=0）起铺；未播段=半透明深色（黑 ~45%，画面透出，实测截图口径）。**最小填充宽=蓝块宽(48dp)+当前时间文字宽**（nPlayer 截图 00:02/45:19 时填充仍完整覆盖 ✕ 与时间文字——实证 max(最小宽, 比例×栏宽) 规则）；**durationMs≤0 时完全不画填充**（整栏仅半透明深底，无最小宽蓝段——无进度可言），拖动/点跳不可用，✕/⋯/文字照常
  - **宿主渐变不挂载**：两侧顶栏宿主 Box 现有 ScrimStrong→透明渐变对 MINIMAL 分支**不叠加**（渐变叠在未播段半透明深底上会成非均匀色，破坏 1:1「画面透出」观感）——栏自带底色即完整视觉
  - **交互**：整栏=slider——横向拖动 scrub（拖动中填充与当前时间标签实时跟随、松手 `onSeek` 提交）+ 单点定跳。**无拖动气泡**（当前时间标签本身即预览，nPlayer 同）；**无缓冲段显示、无章节刻度**（nPlayer 均无，1:1 不加）；热区=栏全高（48dp 口径）
  - **自绘实现**（不复用 NvChapterSlider：全宽填充+文字叠加 vs 底部轨道+时间行，结构差异过大）；手势消费限于本栏高度
- **左侧竖排 3 圆钮**（46dp 半透明灰圆底白图标，钮间距 12dp；垂直中心=屏高 56% 实测口径不变）：**画面旋转**（第一钮；点按 0°→90°→180°→270° 循环，复用既有 rotateVideo 与其现有反馈机制）→ 字幕（CC 图标，开字幕面板）→ 齿轮（=「更多」面板入口）。**锁从左列移除**（底栏首钮就是锁，可达性不减）
- **右侧竖排 3 圆钮（倍速三件套，用户点名要的交互）**：rev4 全文沿用不变——⊕ 点一下 **倍速 +0.1** → 中钮显示当前倍速（**复用 formatSpeedLabel** `1x`/`4.9x`，非 1x 白字高亮，**点击=重置回 1.0x**）→ ⊖ **−0.1**；`nvSpeedStep(current, delta) = snapPlaybackSpeed(current + delta)` 复用仓内 clamp；长按临时倍速期间显示基础速度；提交语义=SpeedSheet.onPick 全套（主侧 setPlaybackSpeed+清双态+applySpeedMute+recordLastSpeed；RMVB 侧 vlcPlayer.rate+uiSpeed+自适应冲刷）
- **底栏**：rev4 全文沿用不变——七钮一行**等距**黑条：锁 │ 上集 │ 快退(skipSec) │ 暂停 │ 快进(skipSec) │ 下集 │ 画面比例；上/下集不可用灰置；**窄幅（<480dp）五钮去锁+比例**（锁经⋯菜单、比例经更多面板仍可达——rev5 起⋯菜单恒有锁行，窄幅去锁不再损失锁入口）
- **底部无进度条**：底栏黑条之下什么都不画；rev4「唤起态 line 进度条原位顶替常驻线」机制对 minimal **作废**（唯一进度显示=顶栏）
- **蓝⋯块＝精简「播放管理」菜单（新组件 MinimalQuickMenu）**：右上下拉深色半透明圆角卡（风格与现有 Sheet/菜单语言统一），行式列表——**锁定 / 上一集 / 下一集 / 画中画 / 投屏 / 退出播放器**（上/下集不可用灰置；**RMVB 键集按 §5.3 剔除画中画/投屏** → 锁定/上集/下集/退出；**投屏行另按 hasCast 门控隐藏**——主侧 playUrl 为 null 时隐藏该行，与经典顶栏藏投屏键同口径；画中画行无需门控，enterPip 自带 API<26 toast）。与底栏锁/上下集重复属**有意冗余**（§5.5 更多面板冗余同先例）
  - **防自动隐藏（rev5 评审 P0-1 定案）**：菜单打开态**上提编排层持有**——契约新增 `quickMenuOpen` 状态 + `onToggleQuickMenu` 回调（§5.1），编排层自动隐藏计时在 `quickMenuOpen=true` 期间**挂起**（主侧 LaunchedEffect 条件门控、RMVB 侧挂起 hide job；这是对 §5.2/§5.4「显隐超时零改动」的**显式豁免**，两侧对称，仅此一处）。**复位口径（rev5 复审 P1-1 补钉）**：`quickMenuOpen` 在任何控制层隐藏出口（锁定收层/全锁/错误态）与样式热切换时由编排层**一律复位 false**（防隐式路径绕过 onToggleQuickMenu 造成旗标残留→自动隐藏永久挂起/跨样式残留）；菜单渲染条件=`quickMenuOpen && 控制层可见`。菜单打开 >4s 控制层与菜单均不消失（冒烟锚 §9）
  - **菜单外区域按下=仅关闭菜单并消费该事件**（不穿透为控制层显隐切换/手势，防「外点同时关菜单+藏控制层」双动作）；再点⋯块关闭
  - 回调走既有（onLock/onPrev/onNext/onPip/onCast/onBack）+ rev5 新增 onToggleQuickMenu；「退出播放器」需新 i18n 键（五语言），其余复用现有文案（锁定/上下集/画中画/投屏 cd 键有 T8 行标签先例）
- **常驻层：删除**（rev2 引入、rev4 保留、rev5 全删）：MINIMAL 档不再挂载任何常驻元素（贴底细线+时间小字都不留），控制层隐藏后画面=纯视频+字幕；经典/streaming 不受影响
- **手势全套不变**：滑亮度/音量、横滑 seek、长按倍速、双击分区、双指缩放；自动隐藏 4s 不变（⋯菜单打开期间挂起除外，见上防自动隐藏条）
- **极简档功能对等落点更新**：暂停=底栏+双击；上下集=底栏+⋯菜单；快退进=底栏+手势；锁=底栏锁钮+⋯菜单+角标（左圆钮锁随 rev5 移除）；倍速=右侧三件套+长按手势+更多面板 SPEED 行；字幕=左圆钮；**旋转=左圆钮第一钮**+更多面板 ROTATE 行；比例=底栏 ⛶（窄幅收更多）；音轨/方向/镜像/PIP/清晰度/投屏/信息=更多面板（播放控制组）；「更多」面板入口=左侧齿轮；「播放管理」菜单入口=顶栏蓝⋯；退出=✕+⋯菜单行

**与 nPlayer 的有意差异（如实记录）**：⊕/⊖ 在 nPlayer 中语义随上下文，我们固定为倍速三件套（用户拍板）；倍速标签用仓内 `1x` 格式（非 nPlayer 的 `1.0x`）；⋯ 菜单内容按 NovaX 实际功能裁剪（nPlayer 的解码器/重复/随机/弹窗播放我们无此功能，不造假入口）；其余布局结构逐元素对应。

### 3.3 长视频风（streaming）＝优酷式

- 顶栏：返回 + 标题 + 右侧图标簇（投屏 / 字幕 / 音轨 / 更多），**平铺不可滚动**（与经典的可滚动动作抽屉区分）；渐变 scrim 与现有顶栏同风格
- 底部**单行**：上集 / 快退 / 暂停 / 快进 / 下集 + `12:34/45:00` 内联时间 + 倍速钮
- 进度线：贴底缘独立细线（NvChapterSlider line 视觉模式），拖动时加粗并浮出预览气泡
- 唤起时上下柔和渐变，**不变暗整屏**
- 其余入口（锁/比例/方向/镜像/旋转/PIP/清晰度/信息）经「更多」面板（§5.5）；锁角标（双击解锁/长按升全锁）行为与三档一致不变
- 窄幅（<480dp）适配：单行底栏去掉倍速钮（倍速经顶栏更多与长按手势仍可达），时间保留
- 兜底播放器（RMVB 宿主）按键集差异：streaming 顶栏图标簇沿用 §5.3 的按键集参数化思想（无投屏键时自动减项）

## 5. 架构设计

### 5.1 控制层契约（Contract）

从现有 `NvPlayerBottomBar` 参数表（position/buffered/duration/isPlaying/speed/lockMode/skipSec + 九回调）提炼扩展为**一份统一契约**：控制层全部状态（进度三值、倍速、锁态、上下集可用性、标题、清晰度档可用性等）+ 全部操作回调（暂停/快退进/上下集/锁/字幕音轨比例方向镜像旋转PIP清晰度投屏信息/各面板入口/返回）。三个样式包接收同一契约，各画各的。

**rev4 契约扩展**：新增 `onSetSpeed: (Float) -> Unit = {}`（直设倍速——现有 `onSpeed` 是开面板不可复用；三件套 ±0.1/重置经此提交）。两侧提交语义与 SpeedSheet.onPick 逐项同款：主侧=setPlaybackSpeed + 清 speedShiftActive/speedShiftLocked + applySpeedMute（KEY_MUTE_ABOVE_2X 同样生效）+ recordLastSpeed 跨会话记忆；RMVB 侧=vlcPlayer 空守卫 + vlcPlayer.rate + uiSpeed 更新 + 自适应冲刷管线。

**rev5 契约扩展（三项，评审 P0-1 定案）**：①`quickMenuOpen: Boolean = false` 状态——⋯精简菜单打开态由**编排层持有**（样式包不得自带影响编排层行为的业务状态），编排层自动隐藏计时在 true 期间挂起（主侧 LaunchedEffect 条件门控、RMVB 侧挂起 hide job；对 §5.2/§5.4「显隐超时零改动」的**显式豁免**，两侧对称仅此一处）；**复位规则**：任何控制层隐藏出口（锁定收层/全锁/错误态）与样式热切换时编排层一律复位 false；②`onToggleQuickMenu: () -> Unit = {}`——⋯块点击切换；③`hasCast: Boolean = true`——⋯菜单投屏行渲染门控（主侧=playUrl 非 null 时 true，RMVB 恒 false；hasQuality 同型先例）。

### 5.2 三样式包与分发

- `classic 包`：现有 NvPlayerTopBar / NvPlayerBottomBar / NvPlayerControlRow / NvChapterSlider 紧凑化后整体作为 classic 实现
- `minimal 包`（rev5 重写）：nPlayer 1:1 布局——**顶栏即进度条** MinimalSeekTopBar（蓝✕/当前时间/标题/剩余时间/蓝⋯横三点；蓝填充=已播从 x=0 起铺、未播半透明深色、最小填充宽覆盖✕+时间；整栏拖动 scrub+单点定跳走 onSeek；自绘不复用 NvChapterSlider）+ 左 3 圆钮（**旋转/字幕/齿轮**）+ 右倍速三件套（⊕/`1x`/⊖，nvSpeedStep 复用）+ 底栏七钮黑条（锁/上集/快退/暂停/快进/下集/比例）+ 蓝⋯精简播放管理菜单 MinimalQuickMenu（锁定/上下集/画中画/投屏/退出播放器，RMVB 减画中画投屏；行动作走既有契约回调，打开/关闭经 rev5 新增 onToggleQuickMenu、投屏行按 hasCast 门控，§5.1）；**无常驻层**（控制层隐藏=全干净）；底部无进度条
- `streaming 包`：新写（图标簇顶栏 + 单行底栏）；贴底进度线同用 NvChapterSlider 的 line 视觉模式（拖动加粗行为经模式参数开启）
- 分发点：PlayerScreen 与 RmvbPlayerActivity（内嵌 Compose）各自按样式枚举选择样式包；编排层既有逻辑不动（评审 P0-3.1 + 二轮 P2-2 接线）：①~~minimal 常驻层槽位~~（**rev5 删除**：rev4 已挂载的常驻层槽位在两侧拆除，`persistentLayerVisible` 对 MINIMAL 不再有意义/恒 false）；②样式分发 when 保持。**rev5 新增接线两处**：③**MINIMAL 分支 controlsBandHeightPx 显式置零**（onSliderBandPx(0f) 或等效——MINIMAL 底部无 slider 无人喂值，播放中热切 classic/streaming→minimal 后旧 band 残留会造成屏底手势死区：按下被整体退场又不被消费，评审 P1-1）；④隐藏计时 quickMenuOpen 门控（§5.1 豁免）。「显隐/超时/controlsTick/手势接线/面板路由零改动」**收窄为 classic/streaming 分支零改动**。

### 5.3 RMVB 顶栏收拢（前置工程）

现状：RmvbPlayerActivity.`ControlsTop()`（L3024–3117）是 NvPlayerTopBar 的平行副本。收拢为**共享顶栏组件 + 参数**，实际差异面（评审 P1-4，全部显式参数化处理）：
- 按键集：RMVB 无 PIP/清晰度/投屏 → 传 null 不渲染
- **按键顺序**：两侧现状不同且存在相对反转（RMVB：比例→方向→镜像→旋转→音轨→字幕→信息→更多，音轨在字幕前；主播放器：字幕→音轨→比例→方向→…——字幕在音轨前）→ 顺序经参数列表传入，两侧各保现状顺序（收拢零重排；二轮评审 P2-5 照实写全）
- contentDescription：统一取「带当前值」口径（aspect/mirror/rotate 度数，信息量只增不减）
- 容器：统一主播放器结构（固定 56dp 高 + displayCutout insets + 渐变移外层）→ **RMVB 页可见微变三处**：①顶栏高度显式化；②渐变从自身移到外层；③displayCutout insets 处理新增（横屏刘海/挖孔适配增强，属改善型微变）（如实列入收拢差异清单，冒烟截图核对）
- 收拢后 RmvbPlayerActivity 接入同一风格分发（classic 用共享顶栏；minimal/streaming 顶栏为新形态，按键集参数同思想）

底栏两件套（NvChapterSlider / NvPlayerControlRow）两播放器本已共用（评审 P2-4：NvPlayerBottomBar 壳仅主播放器使用，RMVB 自组 Column），compact 化自动同享。

### 5.4 共享不动清单（「功能相同」的技术保证）

手势状态机（detectPlayerGestures 及 RMVB 内联版各自保持）、显隐超时（4s/暂停常驻/半锁拦截；**rev5 显隐超时项唯一豁免：quickMenuOpen=true 期间挂起，§5.1**）、三级锁语义（PlayerLockPolicy）、七个功能面板（PlayerSheets / RMVB NvPlayerPopup 各自保持）、PlaybackFeatures、HUD（GestureIndicators / NvVerticalLevelBar）、全部 PlayerPrefs 键语义、controlsBandHeightPx 手势退场计量（热区 48dp 自动收敛，band=热区+24dp slop；**rev5 附注：MINIMAL 分支喂 0，§5.2-③**）。

### 5.5 「更多」面板扩容（功能全集兜底，评审 P0-2 裁决）

- 主播放器 MoreActionsSheet（现 AB 循环+睡眠定时两组）与 RMVB 侧更多面板**各自新增「播放控制」组**，内容为 §3.4 表中该样式下无直接按钮的入口（锁/上下集/快退进/倍速/字幕/音轨/比例/方向/镜像/旋转/PIP/清晰度[有质量档时]/投屏/信息）；**RMVB 侧按 §5.3 键集剔除 PIP/清晰度/投屏三项**（二轮评审 P2-3）
- **三样式共用同一份组内容**（不做样式条件渲染）：经典档用户在更多面板会看到与直接按钮重复的入口——主流做法（B 站/MX Player 菜单同款冗余），换取「任何样式任何功能必达」与实现单一性（**2026-11-19 作废**：用户拍板方案 A「按当前样式智能去重」——外面有直接按钮的入口不重复进组、组空整组隐藏，本条冗余口径作废，见 §12 决策记录）
- 面板视觉零变化（沿用现有 Sheet 样式），仅加组
- 命名防混淆（备忘）：「控制样式」组（§4 切换入口，i18n 键建议 `player_style_group`）与「播放控制」组（本节功能兜底，i18n 键建议 `player_quick_controls`）一字之差同面板共存，i18n 与代码常量须显式区分
- 主/RMVB 两侧双份维护（RMVB 更多面板是独立实现，挂账 §11）

## 12. 决策记录

| 决策 | 结论 | 依据 |
|---|---|---|
| 样式档数 | 三套 | 用户拍板（2026-11-15）；长视频风定位=服务只用过长视频 App 的家庭成员用户（零学习成本） |
| 功能对等口径 | 功能不丢但可换位置 | 用户拍板；nPlayer 同构（次要入口收更多面板+手势承担） |
| 切换入口 | 设置页+播放中更多面板（主/RMVB 两侧） | 用户拍板（nPlayer 先例，方便试用对比）；两侧入口=评审 P1-6 |
| 设置预览 | 必须带迷你示意图，风格与软件统一，纵排三卡 | 用户拍板（系统主题切换式，不盲切）；纵排=评审 P2-3 |
