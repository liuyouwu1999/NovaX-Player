# 播放器控制层三样式可切换 — 设计 Spec

- 日期：2026-11-15（rev2：按对抗评审 3P0+6P1+6P2 修订）
- 状态：待用户审阅
- 关联版本：v1.0.0.23 版本号已 bump 且内容定为 FLAG_SECURE 移除（035ed24）；本功能完成后由用户拍板并入 0.23 一起发或另 bump 0.24
- 前置调研：控制层结构报告（PlayerControls.kt / RmvbPlayerActivity 控制层实测）+ 竞品调研（nPlayer / bilibili / 优酷，素材存 `_research/player_ui/` 私有仓未跟踪目录）

## 1. 背景与动机

用户（项目所有者）反馈：现有控制层唤起时会挡住视频内嵌字幕（字幕常在画面底部），即使加了半锁（不出控制层的手势态）部分用户仍不满意——他们偏好 nPlayer 式极简控制面；同时另一部分用户很喜欢现有样式。另有一类「只用过长视频 App」的用户（NAS 场景中家人的典型画像）对本地播放器布局不熟悉。

结论：**做控制层样式可切换**（三套），样式不同、功能对等，主播放器与 RMVB 兜底播放器同口径。

关键先例：nPlayer 官方内置双皮肤（Classic / Simple Line，设置与播放中均可切）证明该功能形态成熟、用户接受度已被验证。

## 2. 目标与非目标

### 目标
1. 三套控制层样式：**经典**（现状紧凑化）/ **极简**（nPlayer Simple Line 式）/ **长视频风**（优酷式，服务长视频 App 习惯用户）
2. 功能对等原则：**功能不丢，但位置/形态可变**——「更多」面板扩容为功能全集兜底（§5.5），手势语义不变
3. 双切换入口：设置页（带样式预览示意图，不盲切）+ 播放中「更多」面板（**主播放器与 RMVB 两侧都加**），均即时生效
4. 主播放器与兜底播放器永远一致（技术手段：收拢 RMVB 顶栏副本为共享组件 + 同一风格分发）
5. 经典样式紧凑化：底栏总高 154dp → 122dp（-21%），布局、间隔比例、宽/窄双形态完全不变（trackInset 连带变化见 §3.1 注）

### 非目标（明确不做）
- ❌ 强调色自定义（nPlayer 的 Color 功能）
- ❌ per-视频样式记忆（全局一份）
- ❌ 七个功能面板（Subtitle/Audio/Speed/Aspect/Quality/Info/More）**视觉换肤**——三套样式共用同一套面板；唯一例外是 More 面板**内容扩容**（§5.5，内容级非视觉级，且三样式共用同一份扩容）
- ❌ 极简档常驻时间小字的可关设置（固定常驻）
- ❌ 顶栏高度调整（用户只要求下方）
- ❌ 新增任何功能面板（长视频风的选集 = 既有上/下集键 + 更多面板，不新做选集面板）
- ❌ RMVB 手势机与主播放器的已知差异统一（双击分区 1/4-1/2-1/4 vs 1/5-3/5-1/5 维持现状，防回归面扩大——挂账见 §11）
- ❌ 外挂字幕位置避让（调研中的补充思路，不做）

## 3. 样式定义

存储枚举值：`classic`（默认）/ `minimal` / `streaming`。

### 3.1 经典（classic）＝现状 + 紧凑化

布局零变化，仅压缩尺寸（宽幅横屏；来源实测 PlayerControls.kt）：

| 区块 | 现状 → 紧凑 | 备注 |
|---|---|---|
| NvPlayerBottomBar Column bottom padding | 10 → 6dp | |
| NvChapterSlider 触摸热区 | 56 → **48dp**（用户拍板保 48） | 视觉轨道不变（静息 5dp/拖动 8dp、旋钮半径 6/11dp——2026-10-10 S2 改版现行值）；时间贴轨展示不变 |
| NvChapterSlider 拖动气泡 | 气泡锚点上移 8dp | 评审 P1-2：48dp 热区下旋钮顶缘（≈23dp）与气泡底（≈30dp）重叠约 7dp（56dp 时恰不碰）；上移消重叠，「拖动预览气泡不变」指内容与交互，位置微调 |
| NvPlayerControlRow padding top / bottom | 2 / 14 → 1 / 9dp | |
| 暂停钮 PauseSlot | 72 → 58dp，icon 34 → 30dp | |
| 侧键触区（锁/上下集/快退进/倍速） | 60 → 48dp，icon 28 → 24dp | 行高由暂停钮决定，此项只收紧键间呼吸感 |
| **底栏总高** | **154 → 122dp** | **-32dp（约 21%）**；该值为 NvPlayerBottomBar 自身高，不含主播放器偶发叠加的无字幕横幅/还原画面钮（验收口径排除横幅态） |

窄幅档位（`nvNarrowControlMetrics`）同步压缩，比例与三段中心锚定布局不变：

| 档位（maxWidth） | pause 现状 → 新 | 侧键 btn 现状 → 新 | rowIcon |
|---|---|---|---|
| ≥380dp | 62 → 50dp | 52 → 42dp | btn×0.48 比例不变 |
| ≥330dp | 56 → 45dp | 46 → 38dp | 同上 |
| 其余 | 50 → 40dp | 42 → 36dp | **固定 18dp 下限**（36×0.48≈17.3 偏小，最小档 icon 取 18dp，评审 P2-1） |

连带变化（如实记录，评审 P2-2）：窄幅进度条 `trackInset = btn×0.26` 随 btn 缩小而减小 → 窄幅进度条两端向屏缘各延伸约 1.5~2dp，属紧凑化的自然结果。

顶栏（NvPlayerTopBar，56dp 高 / 48dp 键位 / 26dp icon）不动。

### 3.2 极简（minimal）＝nPlayer Simple Line 式

**常驻层（新增，不受控制层显隐门控，评审 P0-3）**：
- 贴屏幕最底缘细线（已播段 NvColors.Primary、未播段半透明白，约 3dp）+ 线右上方常驻半透明小字当前时间（如 `12:34`）——不唤起也能看到进度；时间小字固定常驻，不做开关
- **收起态细线与时间小字均为纯展示、热区为零（不消费任何触摸）**——拖动进度需先 tap 唤起（避免底缘带「单击唤起 vs 横滑全屏 seek vs tap-seek」三方冲突；手势语义不变承诺由此完整成立）
- 常驻层可见性门控（评审 P0-3.3）：未锁/半锁 → 显示（半锁允许看进度，不可交互）；全锁 → 隐藏（锁态=纯净画面）；错误态 → 隐藏
- 唤起后细线切换为可拖模式（NvChapterSlider line 视觉模式，热区 48dp 与经典档同口径），拖动浮出时间气泡，松手 seek

**唤起态**：一条细半透明顶栏（返回 + 标题 + 总时长 + **「更多」键**——评审 P0-1：极简档全部次要功能的唯一入口，nPlayer Simple Line 顶栏同款带菜单键），中央与底部**无任何按钮行**；无整屏 scrim
- 暂停 = 双击手势（既有）；锁/上下集/快退进/倍速/字幕/音轨/比例/方向/镜像/旋转/PIP/清晰度/投屏/信息全部经「更多」面板（§5.5），一个不丢
- 全部手势（滑亮度/音量、横滑 seek、长按倍速、双指缩放、双击分区）原样保留
- 字幕遮挡：唤起态新增元素仅细顶栏+细线+角落时间 ≈ 零遮挡（本样式存在的核心目的）

### 3.3 长视频风（streaming）＝优酷式

- 顶栏：返回 + 标题 + 右侧图标簇（投屏 / 字幕 / 音轨 / 更多），**平铺不可滚动**（与经典的可滚动动作抽屉区分）；渐变 scrim 与现有顶栏同风格
- 底部**单行**：上集 / 快退 / 暂停 / 快进 / 下集 + `12:34/45:00` 内联时间 + 倍速钮
- 进度线：贴底缘独立细线（NvChapterSlider line 视觉模式），拖动时加粗并浮出预览气泡
- 唤起时上下柔和渐变，**不变暗整屏**
- 其余入口（锁/比例/方向/镜像/旋转/PIP/清晰度/信息）经「更多」面板（§5.5）；锁角标（双击解锁/长按升全锁）行为与三档一致不变
- 窄幅（<480dp）适配：单行底栏去掉倍速钮（倍速经顶栏更多与长按手势仍可达），时间保留
- 兜底播放器（RMVB 宿主）按键集差异：streaming 顶栏图标簇沿用 §5.3 的按键集参数化思想（无投屏键时自动减项）

### 3.4 功能对等总表（评审 P1-5 补全，18 入口 × 三档落点）

| 入口 | classic | minimal | streaming |
|---|---|---|---|
| 暂停/播放 | 底栏暂停钮 + 双击 | 双击 | 底栏暂停钮 + 双击 |
| 上/下一集、快退/快进 | 底栏 | 更多面板 + 手势（横滑/双击分区） | 底栏 + 手势 |
| 锁 | 底栏锁钮 + 角标 | 更多面板 + 角标 | 更多面板 + 角标 |
| 倍速 | 底栏倍速钮 + 长按 | 更多面板 + 长按 | 底栏倍速钮（窄幅收更多）+ 长按 |
| 字幕/音轨/信息 | 顶栏动作区 | 更多面板 | 顶栏图标簇 |
| 比例/方向/镜像/旋转/PIP | 顶栏动作区 | 更多面板 | 更多面板 |
| 清晰度（Jellyfin 有质量档时）/投屏 | 顶栏动作区 | 更多面板 | 顶栏图标簇（清晰度收更多） |
| AB 循环/睡眠定时/更多 | 更多面板 | 更多面板 | 更多面板 |

验收按此表逐项核对（§10.4）。

## 4. 交互与入口

| 入口 | 位置 | 形态 |
|---|---|---|
| 设置页 | 设置 → 播放器组 → 「控制层样式」 | 三个选项各带迷你预览示意图（§7），**纵排三行卡**（120dp×3 横排超 360dp 屏内容区，评审 P2-3），单选即时生效 |
| 播放中·主播放器 | 「更多」面板新增「控制样式」组 | 三选一，点击即切，控制层当场换形态（含唤起态切换；形态切换=AnimatedVisibility 内容重组直接切换，不做额外过渡动画，评审 P2-5） |
| 播放中·RMVB 兜底页 | RMVB 侧更多面板（独立实现）同步新增 | 同上；两侧入口双份维护（挂账 §11） |

- 全局一份设置（非 per-视频），两播放器读同一 DataStore 键
- 默认值 `classic`：老用户升级后仅感知经典档紧凑化（布局不变），无其他变化

## 5. 架构设计

### 5.1 控制层契约（Contract）

从现有 `NvPlayerBottomBar` 参数表（position/buffered/duration/isPlaying/speed/lockMode/skipSec + 九回调）提炼扩展为**一份统一契约**：控制层全部状态（进度三值、倍速、锁态、上下集可用性、标题、清晰度档可用性等）+ 全部操作回调（暂停/快退进/上下集/锁/字幕音轨比例方向镜像旋转PIP清晰度投屏信息/各面板入口/返回）。三个样式包接收同一契约，各画各的。

### 5.2 三样式包与分发

- `classic 包`：现有 NvPlayerTopBar / NvPlayerBottomBar / NvPlayerControlRow / NvChapterSlider 紧凑化后整体作为 classic 实现
- `minimal 包`：新写（细顶栏含更多键 + 常驻层）；进度细线 = **NvChapterSlider 增加视觉模式参数**（classic：粗轨+章节刻度+金属旋钮 / line：贴缘细线+拖动气泡），手势内核/热区/band 计量同一份代码换皮，不做第二套手势实现
- `streaming 包`：新写（图标簇顶栏 + 单行底栏）；贴底进度线同用 NvChapterSlider 的 line 视觉模式（拖动加粗行为经模式参数开启）
- 分发点：PlayerScreen 与 RmvbPlayerActivity（内嵌 Compose）各自按样式枚举选择样式包；**编排层既有逻辑不动，新增两处接线**（评审 P0-3.1）：①门控外的 minimal 常驻层槽位（按 §3.2 可见性门控）；②样式分发 when。显隐/超时/controlsTick/手势接线/面板路由零改动。

### 5.3 RMVB 顶栏收拢（前置工程）

现状：RmvbPlayerActivity.`ControlsTop()`（L3024–3117）是 NvPlayerTopBar 的平行副本。收拢为**共享顶栏组件 + 参数**，实际差异面（评审 P1-4，全部显式参数化处理）：
- 按键集：RMVB 无 PIP/清晰度/投屏 → 传 null 不渲染
- **按键顺序**：两侧现状不同（RMVB 比例→方向→…→字幕在末段；主播放器字幕→音轨→比例→…）→ 顺序经参数列表传入，两侧各保现状顺序（收拢零重排）
- contentDescription：统一取「带当前值」口径（aspect/mirror/rotate 度数，信息量只增不减）
- 容器：统一主播放器结构（固定 56dp 高 + displayCutout insets + 渐变移外层）→ **RMVB 页可见微变**：顶栏高度显式化与渐变位置统一（如实列入收拢差异清单，冒烟截图核对）
- 收拢后 RmvbPlayerActivity 接入同一风格分发（classic 用共享顶栏；minimal/streaming 顶栏为新形态，按键集参数同思想）

底栏两件套（NvChapterSlider / NvPlayerControlRow）两播放器本已共用（评审 P2-4：NvPlayerBottomBar 壳仅主播放器使用，RMVB 自组 Column），compact 化自动同享。

### 5.4 共享不动清单（「功能相同」的技术保证）

手势状态机（detectPlayerGestures 及 RMVB 内联版各自保持）、显隐超时（4s/暂停常驻/半锁拦截）、三级锁语义（PlayerLockPolicy）、七个功能面板（PlayerSheets / RMVB NvPlayerPopup 各自保持）、PlaybackFeatures、HUD（GestureIndicators / NvVerticalLevelBar）、全部 PlayerPrefs 键语义、controlsBandHeightPx 手势退场计量（热区 48dp 自动收敛，band=热区+24dp slop）。

### 5.5 「更多」面板扩容（功能全集兜底，评审 P0-2 裁决）

- 主播放器 MoreActionsSheet（现 AB 循环+睡眠定时两组）与 RMVB 侧更多面板**各自新增「播放控制」组**，内容为 §3.4 表中该样式下无直接按钮的入口（锁/上下集/快退进/倍速/字幕/音轨/比例/方向/镜像/旋转/PIP/清晰度[有质量档时]/投屏/信息）
- **三样式共用同一份组内容**（不做样式条件渲染）：经典档用户在更多面板会看到与直接按钮重复的入口——主流做法（B 站/MX Player 菜单同款冗余），换取「任何样式任何功能必达」与实现单一性
- 面板视觉零变化（沿用现有 Sheet 样式），仅加组
- 主/RMVB 两侧双份维护（RMVB 更多面板是独立实现，挂账 §11）

## 6. 数据与设置

- 存储：`novax_player_prefs` DataStore，新键常量 `KEY_CONTROL_STYLE`，存储名 **`novax_control_style`**（对齐现有 34+ 键全部 `novax_` 前缀惯例，评审 P1-3），字符串值 `classic` / `minimal` / `streaming`
- 读取：`rememberPlayerPrefs()` 实时流（现有通道，切换即时生效的机制基础）
- 容错：未知/缺失值一律回退 `classic`（fail-safe）
- 写入：设置页经 SettingsViewModel.set → putPlayerPref；播放中更多面板（两侧）直写同键
- i18n：设置项标题、三样式名称、更多面板组名与全部新增行文案，补齐现有全部语言（五语言）

## 7. 设置页预览组件

`PlaybackGroupPage` 新增「控制层样式」行，内含**纵排**三个可选卡片，各卡片为 **Canvas 绘制的迷你播放器示意图**（非截图、非 emoji 拼贴）：

- 示意内容（黑底圆角卡，宽约 120dp×高约 68dp，用软件现有 NvColors/圆角语言）：
  - 经典：顶部细条（返回点+标题线+格子串）+ 底部两行（七个点 + 粗横线）
  - 极简：顶部细条 + 底部贴缘细线 + 右下角时间点
  - 长视频风：顶部条（返回点+标题线+四点）+ 单行（五点+时间线段）+ 贴缘细线
- 选中态：Primary 色描边高亮；未选中：常规边框
- 风格与当前软件 UI 统一（用户明确要求：像系统主题切换那样的样例，不盲切）

## 8. 兼容与迁移

- 无迁移需求（新键缺失即 classic）
- 已知实现注意：IconButton/自绘 Box 显式 `size()` 覆盖最小触达语义是现状既有行为，压缩后延续；经典紧凑化不影响 `onSliderBandPx` 手势退场计量（band = 热区高度 + 24dp slop，随热区 48dp 自动收敛）
- RMVB 顶栏收拢的回归面：按键顺序保现状参数化 + 容器统一的三处可见微变（§5.3），冒烟核对

## 9. 测试策略

- **JVM 单测**：
  - 样式枚举解析：三合法值 + 未知值/空值回退 classic
  - 键读写端到端（putPlayerPref/rememberPlayerPrefs 通道，仿既有设置键测试）
  - 经典紧凑化档位纯函数：nvNarrowControlMetrics 新档位 + 最小档 icon 18dp 下限锚定
  - 契约参数映射（如 minimal 常驻时间的格式化、常驻层可见性门控纯函数：锁态/错误态矩阵）
- **模拟器冒烟**（证据截图存 `_emutest/`）：
  1. 三套样式切换（两个入口各验一遍），主播放器与 RMVB 兜底页截图一致性对比
  2. 唤起态直接切换：控制层当场换形态（直接切换、无过渡，§4 口径）
  3. 经典紧凑化前后同屏截图对比（高度差可见；排除横幅态）
  4. 带内嵌字幕视频：minimal 唤起态字幕区无遮挡（截图证据）
  5. **§3.4 功能对等总表逐项核对**（18 入口 × 三档全部可达，含 minimal 全经更多面板）
  6. minimal 常驻层门控：未锁显示/半锁显示不可交互/全锁隐藏/错误态隐藏
  7. RMVB 顶栏收拢差异核对：按键顺序与现状一致、容器统一的三处微变截图
- **真机手测（用户验收）**：三套手感、48dp 热区拖动手感不回退、长视频风给家人试用
- **回归底线**：现有 1316 全量单测绿；手势/显隐/锁定相关测试零改动通过

## 10. 验收标准

## 12. 决策记录

| 决策 | 结论 | 依据 |
|---|---|---|
| 样式档数 | 三套 | 用户拍板（2026-11-15）；长视频风定位=服务只用过长视频 App 的家庭成员用户（零学习成本） |
| 功能对等口径 | 功能不丢但可换位置 | 用户拍板；nPlayer 同构（次要入口收更多面板+手势承担） |
| 切换入口 | 设置页+播放中更多面板（主/RMVB 两侧） | 用户拍板（nPlayer 先例，方便试用对比）；两侧入口=评审 P1-6 |
| 设置预览 | 必须带迷你示意图，风格与软件统一，纵排三卡 | 用户拍板（系统主题切换式，不盲切）；纵排=评审 P2-3 |
| 经典进度热区 | 56→48dp（非 46） | 用户拍板保 48：尊重 2026-09-18「判定区域嫌小」历史，防止拖动手感回退 |
| 经典紧凑幅度 | 154→122dp，布局/比例/双形态不变 | 用户拍板「调低一点、按钮小一点，布局别变」；trackInset 连带如实记录 |
| 架构 | 契约+三样式包+分发；RMVB 顶栏参数化收拢（顺序/键集/cd/容器四维参数化） | 结构调研+评审 P1-4 工程量修正 |
| 长视频风形态 | 取优酷式（非 B 站厚底栏） | B 站底栏最厚元凶是弹幕输入框（NovaX 无弹幕）；优酷形态按钮齐全且更薄 |
| minimal 顶栏带「更多」键 | 是 | 评审 P0-1 裁决：极简档次要功能唯一入口，nPlayer Simple Line 同款 |
| More 面板扩容策略 | 三样式共用同一份「播放控制」组（经典档冗余可接受） | 评审 P0-2 裁决：主流做法（B 站/MX 同款冗余），换「任何样式任何功能必达」+实现单一性 |
| minimal 常驻细线交互 | 收起态纯展示零热区，唤起后才可拖；半锁可见不可交互、全锁/错误态隐藏 | 评审 P0-3 裁决：消底缘三方手势冲突，保「手势语义不变」承诺；半锁可见=看进度合理（本功能动因人群即半锁用户） |
