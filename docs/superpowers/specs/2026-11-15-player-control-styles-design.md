# 播放器控制层三样式可切换 — 设计 Spec

- 日期：2026-11-15（rev2：按对抗评审 3P0+6P1+6P2 修订；rev4：极简样式按用户提供的 nPlayer 真机截图重定义为 1:1 复刻，用户第二次拍板）
- 状态：已实现 rev2 版（T1-T10+终审）；rev4 为极简样式重做增量 spec
- 关联版本：v1.0.0.23 版本号已 bump 且内容定为 FLAG_SECURE 移除（035ed24）；本功能完成后由用户拍板并入 0.23 一起发或另 bump 0.24
- 前置调研：控制层结构报告（PlayerControls.kt / RmvbPlayerActivity 控制层实测）+ 竞品调研（nPlayer / bilibili / 优酷，素材存 `_research/player_ui/` 私有仓未跟踪目录）

## 1. 背景与动机

用户（项目所有者）反馈：现有控制层唤起时会挡住视频内嵌字幕（字幕常在画面底部），即使加了半锁（不出控制层的手势态）部分用户仍不满意——他们偏好 nPlayer 式极简控制面；同时另一部分用户很喜欢现有样式。另有一类「只用过长视频 App」的用户（NAS 场景中家人的典型画像）对本地播放器布局不熟悉。

结论：**做控制层样式可切换**（三套），样式不同、功能对等，主播放器与 RMVB 兜底播放器同口径。

关键先例：nPlayer 官方内置双皮肤（Classic / Simple Line，设置与播放中均可切）证明该功能形态成熟、用户接受度已被验证。

## 2. 目标与非目标

### 目标
1. 三套控制层样式：**经典**（现状紧凑化）/ **极简**（nPlayer 1:1 复刻，rev4）/ **长视频风**（优酷式，服务长视频 App 习惯用户）
2. 功能对等原则：**功能不丢，但位置/形态可变**——「更多」面板扩容为功能全集兜底（§5.5），手势语义不变
3. 双切换入口：设置页（带样式预览示意图，不盲切）+ 播放中「更多」面板（**主播放器与 RMVB 两侧都加**），均即时生效
4. 主播放器与兜底播放器永远一致（技术手段：收拢 RMVB 顶栏副本为共享组件 + 同一风格分发）
5. 经典样式紧凑化：底栏总高 154dp → 122dp（-21%），布局、间隔比例、宽/窄双形态完全不变（trackInset 连带变化见 §3.1 注）

### 非目标（明确不做）
- ❌ 强调色自定义（nPlayer 的 Color 功能）
- ❌ per-视频样式记忆（全局一份）
- ❌ 七个功能面板（Subtitle/Audio/Speed/Aspect/Quality/Info/More）**视觉换肤**——三套样式共用同一套面板；唯一例外是 More 面板**内容扩容**（§5.5，内容级非视觉级，且三样式共用同一份扩容）
- ❌ 极简档常驻时间小字的可关设置（固定常驻）
- ❌ 顶栏高度调整（用户只要求下方）
- ❌ 新增任何功能面板（长视频风的选集 = 既有上/下集键 + 更多面板，不新做选集面板）
- ❌ RMVB 手势机与主播放器的已知差异统一（双击分区 1/4-1/2-1/4 vs 1/5-3/5-1/5 维持现状，防回归面扩大——挂账见 §11）
- ❌ 外挂字幕位置避让（调研中的补充思路，不做）

## 3. 样式定义

存储枚举值：`classic`（默认）/ `minimal` / `streaming`。

### 3.1 经典（classic）＝现状 + 紧凑化

布局零变化，仅压缩尺寸（宽幅横屏；来源实测 PlayerControls.kt）：

| 区块 | 现状 → 紧凑 | 备注 |
|---|---|---|
| NvPlayerBottomBar Column bottom padding | 10 → 6dp | |
| NvChapterSlider 触摸热区 | 56 → **48dp**（用户拍板保 48） | 视觉轨道不变（静息 5dp/拖动 8dp、旋钮半径 6/11dp——2026-10-10 S2 改版现行值）；时间贴轨展示不变 |
| NvChapterSlider 拖动气泡 | 气泡锚点上移 8dp | 评审 P1-2：48dp 热区下旋钮顶缘（≈23dp）与气泡底（≈30dp）重叠约 7dp（56dp 时恰不碰）；上移消重叠，「拖动预览气泡不变」指内容与交互，位置微调 |
| NvPlayerControlRow padding top / bottom | 2 / 14 → 1 / 9dp | |
| 暂停钮 PauseSlot | 72 → 58dp，icon 34 → 30dp | |
| 侧键触区（锁/上下集/快退进/倍速） | 60 → 48dp，icon 28 → 24dp | 行高由暂停钮决定，此项只收紧键间呼吸感 |
| **底栏总高** | **154 → 122dp** | **-32dp（约 21%）**；该值为 NvPlayerBottomBar 自身高，不含主播放器偶发叠加的无字幕横幅/还原画面钮（验收口径排除横幅态） |

窄幅档位（`nvNarrowControlMetrics`）同步压缩，比例与三段中心锚定布局不变：

| 档位（maxWidth） | pause 现状 → 新 | 侧键 btn 现状 → 新 | rowIcon |
|---|---|---|---|
| ≥380dp | 62 → 50dp | 52 → 42dp | btn×0.48 比例不变 |
| ≥330dp | 56 → 45dp | 46 → 38dp | 同上 |
| 其余 | 50 → 40dp | 42 → 36dp | **固定 18dp 下限**（36×0.48≈17.3 偏小，最小档 icon 取 18dp，评审 P2-1） |

连带变化（如实记录，评审 P2-2）：窄幅进度条 `trackInset = btn×0.26` 随 btn 缩小而减小 → 窄幅进度条两端向屏缘各延伸约 1.5~2dp，属紧凑化的自然结果。

顶栏（NvPlayerTopBar，56dp 高 / 48dp 键位 / 26dp icon）不动。

### 3.2 极简（minimal）＝ nPlayer 1:1 复刻（rev4，用户第二次拍板）

用户提供了 nPlayer 真机截图（横屏），极简样式按截图**布局结构 1:1 复刻**（dp 值按密度自适应合理取值）；此前 rev2 的"几乎无按钮"设计作废。色板与比例实测自截图：蓝块 `#4578C7`、侧圆钮半透明灰底（黑 55% 附近叠画面）、底栏半透明黑条。

**常驻层（rev2 已实现，保留不变）**：
- 贴屏幕最底缘细线（已播段 NvColors.Primary、未播段半透明白，约 3dp）+ 线右上方常驻半透明小字当前时间——不唤起也能看到进度；零热区纯展示
- 可见性门控（既有）：未锁/半锁显示、全锁/错误态隐藏、唤起时由门控内 line 进度条原位顶替（防双线裁决不变）

**唤起态（rev4 全新布局）**：

```
[蓝✕] 0:02  [文件名标题]  -45:17 [蓝⋯]       ← 顶栏：深色半透明横条 44dp
│                                                    │
🔒(圆钮)                                        ⊕(圆钮)
[CC](圆钮)                                     2x(圆钮)
⚙️(圆钮)                                        ⊖(圆钮)
│                                                    │
│           （画面中央区无遮挡）                        │
│                                                    │
🔒 ⏮上集 ⏪快退 ⏸暂停 ⏩快进 ⏭下集 ⛶比例          ← 底栏：黑色半透明条
──────────────────────────────────────────           ← 贴底缘细线（line 进度条）
```

- **顶栏**（深色半透明横条，高 44dp）：左起——**蓝色圆角方块 ✕**（`#4578C7` 底白图标，44dp 见方，=退出播放器）→ 播放位置时间（`0:02`，数据源=positionMs，**复用仓内 formatTime 不新造格式**）→ 文件名标题（居中弹性占位，省略号截断）→ 剩余时间（`-45:17` 负号格式 = durationMs−positionMs；**durationMs≤0（直播/无时长）时隐藏**，rev2 总时长隐藏先例）→ **蓝色圆角方块 ⋯**（=「更多」面板入口）。两端蓝块 1:1 复刻 nPlayer；`#4578C7` 入 NvColors 体系（如 `NvPlayerBlue`），不散落硬编码
- **左侧竖排 3 圆钮**（屏幕左缘，46dp 半透明灰圆底白图标，钮间距 12dp；**垂直定位=中心位于屏高 56%（偏下 6%，实测用户截图**，非几何正中）：锁（图标随锁态：未锁开锁/半锁实心开锁/全锁闭合锁）→ 字幕（CC 图标，开字幕面板）→ 齿轮（开「更多」面板，第二入口）
- **右侧竖排 3 圆钮（倍速三件套，用户点名要的交互）**：⊕ 点一下 **倍速 +0.1** → 中间圆钮显示当前倍速（**复用仓内 formatSpeedLabel**（`1x`/`4.9x`——PlaybackSpeed.kt 钉死口径不新造格式），非 1x 时白字高亮；**点击=重置回 1.0x**）→ ⊖ 点一下 **倍速 −0.1**。步进实现 `nvSpeedStep(current, delta) = snapPlaybackSpeed(current + delta)`（**复用仓内现成 snapPlaybackSpeed**：0.1 精度+clamp 0.1~5.0，勿造第二份 clamp）；**长按临时倍速（speedShift）期间圆钮显示基础速度不跟随**（临时态由长按胶囊自示）；三件套提交语义=SpeedSheet.onPick 同款全套（setPlaybackSpeed + 清 speedShiftActive/Locked + applySpeedMute + recordLastSpeed 跨会话记忆，主侧；RMVB 侧 vlcPlayer.rate+uiSpeed+自适应冲刷）
- **底栏**（黑色半透明横条）：七钮一行**等距**（实测截图等距分布，间距波动 ±2%）——锁 │ 上集 │ 快退(skipSec) │ 暂停 │ 快进(skipSec) │ 下集 │ 画面比例（开比例面板）。上/下集不可用时灰置（不禁用隐藏，与 nPlayer 一致）。**窄幅（<480dp 竖屏/折叠栏）口径：去锁钮与比例钮**（锁经左圆钮、比例经更多面板仍可达），五钮行=上集/快退/暂停/快进/下集（与 streaming 窄幅去倍速钮同思路）
- **进度条**：贴底缘 line 模式（rev2 已实现，48dp 热区、拖动气泡、tap 即 seek；line 条**不带时间行 Text**——双时间已在顶栏）；细线已播段颜色**维持 NvColors.Primary 橙不跟蓝**（用户截图细线本为暖色，nPlayer 同为橙线+蓝钮并存）
- **手势全套不变**：滑亮度/音量、横滑 seek、长按倍速、双击分区、双指缩放；自动隐藏 4s 不变
- **极简档功能对等落点更新**：暂停=底栏+双击；上下集/快退进=底栏+手势；锁=左圆钮+底栏（窄幅收底栏锁）+角标；倍速=右侧三件套+长按手势+更多面板 SPEED 行（可达全集）；字幕=左圆钮；比例=底栏 ⛶（窄幅收更多）；音轨/方向/镜像/旋转/PIP/清晰度/投屏/信息=更多面板（播放控制组）；「更多」入口=顶栏蓝⋯+左侧齿轮（✕ 为退出不计入口）

**与 nPlayer 的有意差异（如实记录）**：⊕/⊖ 在 nPlayer 中语义随上下文（亮度/音量/倍速面板选择后变），我们固定为倍速三件套（用户拍板：+号点一下加 0.1）；倍速标签用仓内 `1x` 格式（非 nPlayer 的 `1.0x`，全 app 格式统一优先）；其余布局结构逐元素对应。

### 3.3 长视频风（streaming）＝优酷式

- 顶栏：返回 + 标题 + 右侧图标簇（投屏 / 字幕 / 音轨 / 更多），**平铺不可滚动**（与经典的可滚动动作抽屉区分）；渐变 scrim 与现有顶栏同风格
- 底部**单行**：上集 / 快退 / 暂停 / 快进 / 下集 + `12:34/45:00` 内联时间 + 倍速钮
- 进度线：贴底缘独立细线（NvChapterSlider line 视觉模式），拖动时加粗并浮出预览气泡
- 唤起时上下柔和渐变，**不变暗整屏**
- 其余入口（锁/比例/方向/镜像/旋转/PIP/清晰度/信息）经「更多」面板（§5.5）；锁角标（双击解锁/长按升全锁）行为与三档一致不变
- 窄幅（<480dp）适配：单行底栏去掉倍速钮（倍速经顶栏更多与长按手势仍可达），时间保留
- 兜底播放器（RMVB 宿主）按键集差异：streaming 顶栏图标簇沿用 §5.3 的按键集参数化思想（无投屏键时自动减项）

### 3.4 功能对等总表（评审 P1-5 补全，18 入口 × 三档落点）

| 入口 | classic | minimal（rev4） | streaming |

## 4. 交互与入口

| 入口 | 位置 | 形态 |
|---|---|---|
| 设置页 | 设置 → 播放器组 → 「控制层样式」 | 三个选项各带迷你预览示意图（§7），**纵排三行卡**（120dp×3 横排超 360dp 屏内容区，评审 P2-3），单选即时生效 |
| 播放中·主播放器 | 「更多」面板新增「控制样式」组 | 三选一，点击即切，控制层当场换形态（含唤起态切换；形态切换=AnimatedVisibility 内容重组直接切换，不做额外过渡动画，评审 P2-5） |
| 播放中·RMVB 兜底页 | RMVB 侧更多面板（独立实现）同步新增 | 同上；两侧入口双份维护（挂账 §11） |

- 全局一份设置（非 per-视频），两播放器读同一 DataStore 键
- 默认值 `classic`：老用户升级后仅感知经典档紧凑化（布局不变），无其他变化

## 5. 架构设计

### 5.1 控制层契约（Contract）

从现有 `NvPlayerBottomBar` 参数表（position/buffered/duration/isPlaying/speed/lockMode/skipSec + 九回调）提炼扩展为**一份统一契约**：控制层全部状态（进度三值、倍速、锁态、上下集可用性、标题、清晰度档可用性等）+ 全部操作回调（暂停/快退进/上下集/锁/字幕音轨比例方向镜像旋转PIP清晰度投屏信息/各面板入口/返回）。三个样式包接收同一契约，各画各的。

**rev4 契约扩展**：新增 `onSetSpeed: (Float) -> Unit = {}`（直设倍速——现有 `onSpeed` 是开面板不可复用；三件套 ±0.1/重置经此提交）。两侧提交语义与 SpeedSheet.onPick 逐项同款：主侧=setPlaybackSpeed + 清 speedShiftActive/speedShiftLocked + applySpeedMute（KEY_MUTE_ABOVE_2X 同样生效）+ recordLastSpeed 跨会话记忆；RMVB 侧=vlcPlayer 空守卫 + vlcPlayer.rate + uiSpeed 更新 + 自适应冲刷管线。

### 5.2 三样式包与分发

- `classic 包`：现有 NvPlayerTopBar / NvPlayerBottomBar / NvPlayerControlRow / NvChapterSlider 紧凑化后整体作为 classic 实现
- `minimal 包`（rev4 重写）：nPlayer 1:1 布局——蓝块顶栏（✕/当前时间/标题/剩余时间/⋯）+ 左侧 3 圆钮（锁/字幕/齿轮）+ 右侧倍速三件套圆钮（⊕/`1x` 格式显示/⊖，`nvSpeedStep=snapPlaybackSpeed` 复用步进）+ 底栏七钮黑条（锁/上集/快退/暂停/快进/下集/比例）+ 贴底 line 进度条 + 常驻层（rev2 已实现保留）；进度细线仍用 NvChapterSlider line 视觉模式（手势内核/热区/band 同口径）
- `streaming 包`：新写（图标簇顶栏 + 单行底栏）；贴底进度线同用 NvChapterSlider 的 line 视觉模式（拖动加粗行为经模式参数开启）
- 分发点：PlayerScreen 与 RmvbPlayerActivity（内嵌 Compose）各自按样式枚举选择样式包；**编排层既有逻辑不动，两侧各新增两处接线**（评审 P0-3.1 + 二轮 P2-2）：①门控外的 minimal 常驻层槽位（按 §3.2 可见性门控，两播放器对称）；②样式分发 when。显隐/超时/controlsTick/手势接线/面板路由零改动。

### 5.3 RMVB 顶栏收拢（前置工程）

现状：RmvbPlayerActivity.`ControlsTop()`（L3024–3117）是 NvPlayerTopBar 的平行副本。收拢为**共享顶栏组件 + 参数**，实际差异面（评审 P1-4，全部显式参数化处理）：
- 按键集：RMVB 无 PIP/清晰度/投屏 → 传 null 不渲染
- **按键顺序**：两侧现状不同且存在相对反转（RMVB：比例→方向→镜像→旋转→音轨→字幕→信息→更多，音轨在字幕前；主播放器：字幕→音轨→比例→方向→…——字幕在音轨前）→ 顺序经参数列表传入，两侧各保现状顺序（收拢零重排；二轮评审 P2-5 照实写全）
- contentDescription：统一取「带当前值」口径（aspect/mirror/rotate 度数，信息量只增不减）
- 容器：统一主播放器结构（固定 56dp 高 + displayCutout insets + 渐变移外层）→ **RMVB 页可见微变三处**：①顶栏高度显式化；②渐变从自身移到外层；③displayCutout insets 处理新增（横屏刘海/挖孔适配增强，属改善型微变）（如实列入收拢差异清单，冒烟截图核对）
- 收拢后 RmvbPlayerActivity 接入同一风格分发（classic 用共享顶栏；minimal/streaming 顶栏为新形态，按键集参数同思想）

底栏两件套（NvChapterSlider / NvPlayerControlRow）两播放器本已共用（评审 P2-4：NvPlayerBottomBar 壳仅主播放器使用，RMVB 自组 Column），compact 化自动同享。

### 5.4 共享不动清单（「功能相同」的技术保证）

手势状态机（detectPlayerGestures 及 RMVB 内联版各自保持）、显隐超时（4s/暂停常驻/半锁拦截）、三级锁语义（PlayerLockPolicy）、七个功能面板（PlayerSheets / RMVB NvPlayerPopup 各自保持）、PlaybackFeatures、HUD（GestureIndicators / NvVerticalLevelBar）、全部 PlayerPrefs 键语义、controlsBandHeightPx 手势退场计量（热区 48dp 自动收敛，band=热区+24dp slop）。

### 5.5 「更多」面板扩容（功能全集兜底，评审 P0-2 裁决）

- 主播放器 MoreActionsSheet（现 AB 循环+睡眠定时两组）与 RMVB 侧更多面板**各自新增「播放控制」组**，内容为 §3.4 表中该样式下无直接按钮的入口（锁/上下集/快退进/倍速/字幕/音轨/比例/方向/镜像/旋转/PIP/清晰度[有质量档时]/投屏/信息）；**RMVB 侧按 §5.3 键集剔除 PIP/清晰度/投屏三项**（二轮评审 P2-3）
- **三样式共用同一份组内容**（不做样式条件渲染）：经典档用户在更多面板会看到与直接按钮重复的入口——主流做法（B 站/MX Player 菜单同款冗余），换取「任何样式任何功能必达」与实现单一性
- 面板视觉零变化（沿用现有 Sheet 样式），仅加组
- 命名防混淆（备忘）：「控制样式」组（§4 切换入口，i18n 键建议 `player_style_group`）与「播放控制」组（本节功能兜底，i18n 键建议 `player_quick_controls`）一字之差同面板共存，i18n 与代码常量须显式区分
- 主/RMVB 两侧双份维护（RMVB 更多面板是独立实现，挂账 §11）

## 11. 挂账与后续（不阻塞本 spec）

- RMVB 手势机双击分区与主播放器的历史差异（1/4-1/2-1/4 vs 1/5-3/5-1/5）——本次不动，后续可立项统一
- RMVB 手势/显隐仍是人工同步的第二实现（本次只收顶栏）；彻底收敛为单一 Controller 属更大重构，另行评估
- RMVB 更多面板（含新「控制样式」入口与「播放控制」组）是独立第二实现，与主播放器双份维护——长期应随面板收敛统一
- 极简档常驻时间小字若用户反馈要可关，加设置项成本极低
- 版本协调：v1.0.0.23 版本号已 bump（内容=FLAG_SECURE 移除）；本功能完成后并入 0.23 一起发（升级说明并入）或 bump 0.24，用户届时拍板
