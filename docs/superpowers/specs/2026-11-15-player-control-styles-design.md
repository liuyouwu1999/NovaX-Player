# 播放器控制层三样式可切换 — 设计 Spec

- 日期：2026-11-15
- 状态：待用户审阅
- 关联版本：随 v1.0.0.23 或后续版本发布（发版时由用户拍板搭车或另起版本号）
- 前置调研：控制层结构报告（PlayerControls.kt / RmvbPlayerActivity 控制层实测）+ 竞品调研（nPlayer / bilibili / 优酷，素材存 `_research/player_ui/` 私有仓未跟踪目录）

## 1. 背景与动机

用户（项目所有者）反馈：现有控制层唤起时会挡住视频内嵌字幕（字幕常在画面底部），即使加了半锁（不出控制层的手势态）部分用户仍不满意——他们偏好 nPlayer 式极简控制面；同时另一部分用户很喜欢现有样式。另有一类「只用过长视频 App」的用户（NAS 场景中家人的典型画像）对本地播放器布局不熟悉。

结论：**做控制层样式可切换**（三套），样式不同、功能对等，主播放器与 RMVB 兜底播放器同口径。

关键先例：nPlayer 官方内置双皮肤（Classic / Simple Line，设置与播放中均可切）证明该功能形态成熟、用户接受度已被验证。

## 2. 目标与非目标

### 目标
1. 三套控制层样式：**经典**（现状紧凑化）/ **极简**（nPlayer Simple Line 式）/ **长视频风**（优酷式，服务长视频 App 习惯用户）
2. 功能对等原则：**功能不丢，但位置/形态可变**——极简与长视频风把次要入口收进「更多」面板，手势语义不变
3. 双切换入口：设置页（带样式预览示意图，不盲切）+ 播放中「更多」面板，均即时生效
4. 主播放器与兜底播放器永远一致（技术手段：收拢 RMVB 顶栏副本为共享组件 + 同一风格分发）
5. 经典样式紧凑化：底栏总高 154dp → 122dp（-21%），布局、间隔比例、宽/窄双形态完全不变

### 非目标（明确不做）
- ❌ 强调色自定义（nPlayer 的 Color 功能）
- ❌ per-视频样式记忆（全局一份）
- ❌ 七个功能面板（Subtitle/Audio/Speed/Aspect/Quality/Info/More）跟随换肤——三套样式共用同一套面板
- ❌ 极简档常驻时间小字的可关设置（固定常驻）
- ❌ 顶栏高度调整（用户只要求下方）
- ❌ 新增任何功能面板（长视频风的选集 = 既有上/下集键 + 更多面板，不新做选集面板）
- ❌ RMVB 手势机与主播放器的已知差异统一（双击分区 1/4-1/2-1/4 vs 1/5-3/5-1/5 维持现状，防回归面扩大——挂账见 §11）
- ❌ 外挂字幕位置避让（调研中的补充思路，不做）

## 3. 样式定义

存储枚举值：`classic`（默认）/ `minimal` / `streaming`。

### 3.1 经典（classic）＝现状 + 紧凑化

布局零变化，仅压缩尺寸（宽幅横屏；来源实测 PlayerControls.kt）：

| 区块 | 现状 → 紧凑 | 备注 |
|---|---|---|
| NvPlayerBottomBar Column bottom padding | 10 → 6dp | |
| NvChapterSlider 触摸热区 | 56 → **48dp**（用户拍板保 48） | 视觉轨道 4dp、拖动预览气泡、时间贴轨展示全部不变；历史 2026-09-18「判定区域嫌小」从 48→56，本次回落 48 属用户知情决策 |
| NvPlayerControlRow padding top / bottom | 2 / 14 → 1 / 9dp | |
| 暂停钮 PauseSlot | 72 → 58dp，icon 34 → 30dp | |
| 侧键触区（锁/上下集/快退进/倍速） | 60 → 48dp，icon 28 → 24dp | 行高由暂停钮决定，此项只收紧键间呼吸感 |
| **底栏总高** | **154 → 122dp** | **-32dp（约 21%）** |

窄幅档位（`nvNarrowControlMetrics`）同步压缩，比例与三段中心锚定布局不变：

| 档位（maxWidth） | pause 现状 → 新 | 侧键 btn 现状 → 新 | rowIcon |
|---|---|---|---|
| ≥380dp | 62 → 50dp | 52 → 42dp | btn×0.48 比例不变 |
| ≥330dp | 56 → 45dp | 46 → 38dp | 同上 |
| 其余 | 50 → 40dp | 42 → 36dp | 同上 |

顶栏（NvPlayerTopBar，56dp 高 / 48dp 键位 / 26dp icon）不动。

### 3.2 极简（minimal）＝nPlayer Simple Line 式

- **收起态（默认）**：贴屏幕最底缘细线（已播段 NvColors.Primary、未播段半透明白，约 3dp）；线右上方常驻半透明小字当前时间（如 `12:34`），不唤起也能看到进度——时间小字固定常驻，不做开关
- **唤起态**：仅一条细半透明顶栏（返回 + 标题 + 总时长），中央与底部**无任何按钮行**；无整屏 scrim
- 进度细线拖动时浮出时间气泡（当前/目标时间），松手 seek，手感与现有一致；触摸热区 48dp 与经典档同口径
- 暂停 = 双击手势（既有）；锁/上下集/快退进/字幕/音轨/比例/倍速/信息等全部入口在「更多」面板，一个不丢
- 全部手势（滑亮度/音量、横滑 seek、长按倍速、双指缩放、双击分区）原样保留
- 字幕遮挡：唤起态新增元素仅细顶栏+细线+角落时间 ≈ 零遮挡（本样式存在的核心目的）

### 3.3 长视频风（streaming）＝优酷式

- 顶栏：返回 + 标题 + 右侧图标簇（投屏 / 字幕 / 音轨 / 更多），**平铺不可滚动**（与经典的可滚动动作抽屉区分）；渐变 scrim 与现有顶栏同风格
- 底部**单行**：上集 / 快退 / 暂停 / 快进 / 下集 + `12:34/45:00` 内联时间 + 倍速钮
- 进度线：贴底缘独立细线，拖动时加粗并浮出预览气泡
- 唤起时上下柔和渐变，**不变暗整屏**
- 窄幅（<480dp）适配：单行底栏去掉倍速钮（倍速经顶栏更多与长按手势仍可达），时间保留
- 兜底播放器（RMVB 宿主）按键集差异：streaming 顶栏图标簇沿用 §5.3 的按键集参数化思想（无投屏键时自动减项）

## 4. 交互与入口

| 入口 | 位置 | 形态 |
|---|---|---|
| 设置页 | 设置 → 播放器组 → 「控制层样式」 | 三个选项各带迷你预览示意图（§7），单选，即时生效 |
| 播放中 | 「更多」面板新增「控制样式」组 | 三选一（复用面板现有行样式），点击即切，控制层当场换形态（含唤起态切换） |

- 全局一份设置（非 per-视频），两播放器读同一 DataStore 键
- 默认值 `classic`：老用户升级后仅感知经典档紧凑化（布局不变），无其他变化

## 5. 架构设计

### 5.1 控制层契约（Contract）

从现有 `NvPlayerBottomBar` 参数表（position/buffered/duration/isPlaying/speed/lockMode/skipSec + 九回调）提炼扩展为**一份统一契约**：控制层全部状态（进度三值、倍速、锁态、上下集可用性、标题等）+ 全部操作回调（暂停/快退进/上下集/锁/各面板入口/返回）。三个样式包接收同一契约，各画各的。

### 5.2 三样式包与分发

- `classic 包`：现有 NvPlayerTopBar / NvPlayerBottomBar / NvPlayerControlRow / NvChapterSlider 紧凑化后整体作为 classic 实现
- `minimal 包`：新写（细顶栏 + 常驻时间）；进度细线 = **NvChapterSlider 增加视觉模式参数**（classic：粗轨+章节刻度+金属旋钮 / line：贴缘细线+拖动气泡），手势内核/热区/band 计量同一份代码换皮，不做第二套手势实现
- `streaming 包`：新写（图标簇顶栏 + 单行底栏）；贴底进度线同用 NvChapterSlider 的 line 视觉模式（拖动加粗行为经模式参数开启）
- 分发点：PlayerScreen 与 RmvbScreen 各自按样式枚举选择样式包；**编排层（PlayerScreen.kt 的显隐/超时/controlsTick/手势接线/面板路由）与 RmvbScreen 的对应逻辑不动**

### 5.3 RMVB 顶栏收拢（前置工程）

现状：RmvbPlayerActivity.`ControlsTop()`（L3024–3117）是 NvPlayerTopBar 的平行副本。收拢为**共享顶栏组件 + 按键集参数**（RMVB 无 PIP/清晰度/投屏，传 null 即不渲染该键），删除副本。底栏三件套（NvChapterSlider / NvPlayerControlRow）两播放器本已共用，compact 化自动同享。RmvbPlayerActivity 接入同一风格分发后，两播放器样式永远同步。

### 5.4 共享不动清单（「功能相同」的技术保证）

手势状态机（detectPlayerGestures 及 RMVB 内联版各自保持）、显隐超时（4s/暂停常驻/半锁拦截）、三级锁语义（PlayerLockPolicy）、七个功能面板（PlayerSheets / RMVB NvPlayerPopup 各自保持）、PlaybackFeatures、HUD（GestureIndicators / NvVerticalLevelBar）、全部 PlayerPrefs 键语义。

## 6. 数据与设置

- 存储：`novax_player_prefs` DataStore，新键常量 `KEY_CONTROL_STYLE`，存储名 `player_control_style`，字符串值 `classic` / `minimal` / `streaming`（命名对齐现有键惯例，实现时以 PlayerPrefs.kt 现有风格为准）
- 读取：`rememberPlayerPrefs()` 实时流（现有通道，切换即时生效的机制基础）
- 容错：未知/缺失值一律回退 `classic`（fail-safe）
- 写入：设置页经 SettingsViewModel.set → putPlayerPref；播放中更多面板直写同键
- i18n：设置项标题、三样式名称、更多面板组名，补齐现有全部语言（五语言）

## 7. 设置页预览组件

`PlaybackGroupPage` 新增「控制层样式」行，内含三个可选卡片，各卡片为 **Canvas 绘制的迷你播放器示意图**（非截图、非 emoji 拼贴）：

- 示意内容（黑底圆角卡，宽约 120dp×高约 68dp，用软件现有 NvColors/圆角语言）：
  - 经典：顶部细条（返回点+标题线+格子串）+ 底部两行（七个点 + 粗横线）
  - 极简：顶部细条 + 底部贴缘细线 + 右下角时间点
  - 长视频风：顶部条（返回点+标题线+四点）+ 单行（五点+时间线段）+ 贴缘细线
- 选中态：Primary 色描边高亮；未选中：常规边框
- 风格与当前软件 UI 统一（用户明确要求：像系统主题切换那样的样例，不盲切）

## 8. 兼容与迁移

- 无迁移需求（新键缺失即 classic）
- 已知实现注意：IconButton/自绘 Box 显式 `size()` 覆盖最小触达语义是现状既有行为，压缩后延续；经典紧凑化不影响 `onSliderBandPx` 手势退场计量（band = 热区高度 + 24dp slop，随热区 48dp 自动收敛）
- RMVB 顶栏收拢的回归面：按键集差异（无 PIP/清晰度/投屏）需冒烟核对

## 9. 测试策略

- **JVM 单测**：
  - 样式枚举解析：三合法值 + 未知值/空值回退 classic
  - 键读写端到端（putPlayerPref/rememberPlayerPrefs 通道，仿既有设置键测试）
  - 经典紧凑化档位纯函数：nvNarrowControlMetrics 新档位锚定
  - 契约参数映射（如 minimal 常驻时间的格式化）
- **模拟器冒烟**（证据截图存 `_emutest/`）：
  1. 三套样式切换（两个入口各验一遍），主播放器与 RMVB 兜底页截图一致性对比
  2. 唤起态直接切换：控制层当场换形态
  3. 经典紧凑化前后同屏截图对比（高度差可见）
  4. 带内嵌字幕视频：minimal 唤起态字幕区无遮挡（截图证据）
  5. 三套样式下功能对等清单核对（锁/上下集/快退进/倍速/字幕/音轨/比例/信息/更多 全部可达）
- **真机手测（用户验收）**：三套手感、48dp 热区拖动手感不回退、长视频风给家人试用
- **回归底线**：现有 1316 全量单测绿；手势/显隐/锁定相关测试零改动通过

## 10. 验收标准

1. 三套样式在两播放器中切换即时生效且形态一致（截图对比）
2. minimal 唤起态不遮挡内嵌字幕区（冒烟截图证据）
3. 经典档底栏高度 154→122dp 实测达标，拖动手感用户验收通过
4. §9 功能对等清单三套全绿
5. 设置页三张预览图与实际形态对应、风格统一
6. 全量单测绿 + gitleaks 零泄漏

## 11. 挂账与后续（不阻塞本 spec）

- RMVB 手势机双击分区与主播放器的历史差异（1/4-1/2-1/4 vs 1/5-3/5-1/5）——本次不动，后续可立项统一
- RMVB 手势/显隐仍是人工同步的第二实现（本次只收顶栏）；彻底收敛为单一 Controller 属更大重构，另行评估
- 极简档常驻时间小字若用户反馈要可关，加设置项成本极低
- v1.0.0.23 发版协调：本功能完成后的版本号归属（搭 0.23 或 bump 0.24）由用户届时拍板

## 12. 决策记录

| 决策 | 结论 | 依据 |
|---|---|---|
| 样式档数 | 三套 | 用户拍板（2026-11-15）；长视频风定位=服务只用过长视频 App 的家庭成员用户（零学习成本） |
| 功能对等口径 | 功能不丢但可换位置 | 用户拍板；nPlayer 同构（次要入口收更多面板+手势承担） |
| 切换入口 | 设置页+播放中更多面板 | 用户拍板（nPlayer 先例，方便试用对比） |
| 设置预览 | 必须带迷你示意图，风格与软件统一 | 用户拍板（系统主题切换式，不盲切） |
| 经典进度热区 | 56→48dp（非 46） | 用户拍板保 48：尊重 2026-09-18「判定区域嫌小」历史，防止拖动手感回退 |
| 经典紧凑幅度 | 154→122dp，布局/比例/双形态不变 | 用户拍板「调低一点、按钮小一点，布局别变」 |
| 架构 | 契约+三样式包+分发；RMVB 顶栏参数化收拢 | 结构调研：PlayerControls 已是纯视觉组件、底栏三件套双播放器共用、抽象缝现成 |
| 长视频风形态 | 取优酷式（非 B 站厚底栏） | B 站底栏最厚元凶是弹幕输入框（NovaX 无弹幕）；优酷形态按钮齐全且更薄，对字幕压力小 |
